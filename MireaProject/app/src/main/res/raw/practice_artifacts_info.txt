Что нужно добавить после запуска приложения на устройстве или эмуляторе:
1. Скриншот файла SharedPreferences из Device File Explorer.
2. Скриншоты или экспортированные файлы, созданные экраном "Работа с файлами".
3. При необходимости аудиофайл и фотоматериалы, полученные в приложении.
4. Для практики №7: файл google-services.json из проекта Firebase в каталог app.
5. Для практики №7: скриншот экрана входа после регистрации/авторизации пользователя.
6. Для практики №7: скриншот Firebase Console со списком пользователей и зарегистрированным email.
7. Для практики №8: скриншот экрана "Заведения" с OpenStreetMap-картой и маркерами.
8. Для практики №8: скриншот диалога с адресом и описанием после нажатия на маркер.
9. Для практики №8: при проверке текущего местоположения указать координаты эмулятора в Extended Controls | Location.

Текущий проект уже содержит:
- фрагмент "Профиль" с сохранением в SharedPreferences;
- фрагмент "Работа с файлами" с созданием записи через Floating Action Button;
- экран датчиков с определением направления на север;
- экран камеры для фотозаметки;
- экран диктофона для записи и воспроизведения голоса.
- экран входа через Firebase Authentication;
- экран "Сеть" с получением JSON из удаленного ресурса.
- экран "Заведения" с OpenStreetMap-картой, маркерами, описаниями и определением текущего местоположения.
