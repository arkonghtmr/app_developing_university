Практическая работа для MireaProject.

Что нужно добавить сюда после запуска приложения на устройстве или эмуляторе:
1. Скриншот файла SharedPreferences из Device File Explorer.
2. Скриншоты или экспортированные файлы, созданные экраном "Работа с файлами".
3. При необходимости аудиофайл и фотоматериалы, полученные в приложении.

Текущий проект уже содержит:
- фрагмент "Профиль" с сохранением в SharedPreferences;
- фрагмент "Работа с файлами" с созданием записи через Floating Action Button;
- экран датчиков с определением направления на север;
- экран камеры для фотозаметки;
- экран диктофона для записи и воспроизведения голоса.
