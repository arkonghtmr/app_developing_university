## Тема

Сетевое взаимодействие в Android и авторизация пользователей через Firebase.

## Цель работы

Целью практической работы являлось добавление в проект `MireaProject` экрана входа с использованием `Firebase Authentication`, а также создание фрагмента, который получает информацию из сетевого ресурса и отображает ее в интерфейсе приложения.

---

## Выполненные задания

### 1. Экран входа через Firebase

В проект добавлена отдельная `LoginActivity`, которая теперь является точкой входа приложения. В манифесте `MainActivity` больше не запускается напрямую, а открывается после успешной авторизации пользователя.

Экран входа реализует:

- ввод электронной почты и пароля;
- создание аккаунта через `createUserWithEmailAndPassword`;
- вход через `signInWithEmailAndPassword`;
- отправку письма подтверждения почтового адреса;
- выход из учетной записи;
- изменение интерфейса в зависимости от состояния авторизации пользователя.

Для сборки проекта без привязки к конкретному аккаунту Firebase добавлена проверка наличия конфигурации. Если файл `google-services.json` отсутствует, экран показывает сообщение о необходимости настройки Firebase и блокирует кнопки регистрации и входа.

После добавления `app/google-services.json` Gradle автоматически подключит плагин `com.google.gms.google-services`, а экран начнет работать с реальным проектом Firebase.

### 2. Переход на главный экран после авторизации

После успешного входа выполняется переход из `LoginActivity` в `MainActivity`. В боковое меню главного экрана добавлен пункт выхода, который вызывает `FirebaseAuth.signOut()` и возвращает пользователя на экран авторизации.

### 3. Сетевой фрагмент

В `MireaProject` добавлен фрагмент `NetworkFragment` и пункт меню `Сеть`.

Фрагмент выполняет HTTPS-запрос к открытому API GitHub:

```text
https://api.github.com/repos/android/nowinandroid
```

Запрос выполняется в фоновом потоке через `HttpURLConnection`, поэтому главный UI-поток не блокируется. Ответ приходит в формате JSON и разбирается через `JSONObject`.

На экран выводятся:

- имя репозитория;
- описание;
- количество звезд;
- основной язык проекта;
- дата последнего обновления;
- ссылка на источник.

### 4. Обновление ресурсов проекта

В проект добавлены:

- разрешение `INTERNET` в `AndroidManifest.xml`;
- строки интерфейса для Firebase-авторизации;
- строки интерфейса для сетевого фрагмента;
- пункт `Сеть` в `drawer_menu.xml`;
- пункт `Выход` в `drawer_menu.xml`;
- информация о практике №7 в `res/raw/practice_artifacts_info.txt`.

## Необходимые материалы после запуска

Для окончательного отчета по Firebase необходимо добавить в `app/src/main/res/raw` или приложить отдельно:

- скриншот экрана приложения с авторизованным пользователем;
- скриншот Firebase Console со списком пользователей и зарегистрированным email;

Файл `google-services.json`, полученный из Firebase Console, должен быть размещен в каталоге `app/`, чтобы приложение подключилось к реальному Firebase-проекту.

Эти материалы требуют доступа к личному Google/Firebase-аккаунту, поэтому они должны быть получены после запуска проекта на устройстве или эмуляторе.
